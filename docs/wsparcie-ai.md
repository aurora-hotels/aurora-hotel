# Wsparcie narzędzi i sprawdzenie kodu

Przy przygotowaniu aplikacji użyto narzędzi AI do implementacji serwera i interfejsu, przygotowania testów, analizy błędów oraz redakcji dokumentacji. Adrian koordynował przygotowanie całości również poza swoją formalną rolą. Samo wygenerowanie pliku nie oznacza jego odbioru przez zespół.

Kod sprawdzamy przez kontrolę typów, testy API, testy reguł rezerwacji, scenariusze przeglądarkowe i przegląd zmian. Błędy znalezione w tych próbach wymagają poprawki i ponownego testu. Wynik testu z symulatorem nie potwierdza działania rzeczywistego API innej grupy.
