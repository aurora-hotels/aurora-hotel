# Aurora Hotels — projekt C

Projekt studencki z przedmiotu Projekt Zespołowy: prototyp obsługi hotelu i pakietów wypoczynkowych. Korzystamy z fikcyjnych danych i przygotowujemy demonstrację na zajęcia.

## Zakres

- konta klientów, oferta pokoi i sprawdzanie dostępności;
- rezerwacje, zmiany i anulowanie pobytu;
- obsługa przyjazdu i wyjazdu przez recepcję;
- pakiety oraz integracje z projektami A (masaże), B (treningi) i D (vouchery).

Pierwsza działająca wersja obejmie konta, pokoje i rezerwację. Integracje dojdą w kolejnych etapach.

## Stan projektu

Przygotowane jest środowisko pracy i wstępny plan. Implementacja aplikacji jeszcze się nie rozpoczęła.

Planowany stos: React + TypeScript, Express, Prisma i SQLite. Instrukcję uruchomienia dodamy wraz ze szkieletem aplikacji.

## Proste zasady

1. Wybierz przypisane zadanie w Jirze i zmień status na W toku.
2. Pracuj na gałęzi nazwanej np. `KAN-9-rezerwacja`.
3. W pull requeście podaj numer zadania i napisz, jak sprawdzono zmianę.
4. Druga osoba sprawdza zmianę przed zakończeniem zadania.
